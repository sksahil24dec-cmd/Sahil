# Security Policy
## Supported Versions
Only the latest major release of the Sahil Programming Language core receives security updates.

| Version | Supported |
| :--- | :--- |
| 1.x.x | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within the Sahil core engine, please report it through private channels. All verified issues will be patched promptly.
